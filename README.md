# Udemy Clone – Online Learning Website

This is a Udemy-inspired online learning website created using **HTML5 and CSS3**.

## Features

* Navigation bar with search option
* Course categories
* Recommended courses
* Topics recommended for you
* Most popular courses
* Course cards with ratings and prices
* Footer section
* Google Fonts integration
* Font Awesome icons

## Technologies Used

* HTML5
* CSS3
* Google Fonts
* Font Awesome
